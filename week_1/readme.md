# Lab 1: Online Resume Web Page

## Aim
To design and develop a responsive, semantic online resume web page using HTML5 and CSS3 features.

## Features Implemented
*   **Semantic HTML5:** Structured using `<header>`, `<main>`, `<section>`, and `<footer>`.
*   **Modern Layout:** Built utilizing **CSS Flexbox** for a responsive, clean two-column desktop presentation.
*   **Data Layouts:** Organized education details inside a structured `<table>` and skills using nested elements.
*   **Typography & Styling:** Enhanced with custom CSS fonts, custom padding/margins, and custom borders.

## File Structure
*   `index.html` - Contains the structural markup and text content.
*   `style.css` - Contains the responsive Flexbox rules and visual styling.

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox).
